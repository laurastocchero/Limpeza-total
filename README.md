# Limpeza Total - Website Institucional e Catálogo Digital
Projeto desenvolvido para a disciplina de Engenharia de Software e Desenvolvimento Ágil de Soluções (Projeto 4 - FESP 2026).

## Funcionalidades do MVP
- Catálogo completo com 72 produtos divididos em 6 categorias
- Busca dinâmica em tempo real (ignorando maiúsculas/minúsculas e acentos)
- Carrinho de compras local com persistência via `localStorage` e cálculo automático
- Páginas de dicas de limpeza, contato via WhatsApp e layout responsivo
